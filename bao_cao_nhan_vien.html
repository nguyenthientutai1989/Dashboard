Báo cáo nhân viênPhân tích file xuất bán theo nhân viên giao hàng

1. Chọn file dữ liệu

Hệ số quy đổi và cách tính doanh thu

DT quy đổi = hệ số ngành × (DT thực + (hệ số trả góp − 1) × DT trả góp). Hệ số được lưu lại trên trình duyệt này. Ngành nào chưa có hệ số sẽ tính 1,0 (ô màu vàng).

2. Tuỳ chỉnh và xuất báo cáo

Chọn file Excel rồi bấm “Phân tích dữ liệu” để tạo báo cáo.
